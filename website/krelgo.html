A gaming OS for the Lenovo Legion Go

Krelboyne Go (KrelGo) is a Debian 13 system for the original Legion Go. It boots to a dark teal Xfce desktop in landscape at 144 Hz, with Steam, Proton, RetroArch and ES-DE ready to play.

What it is

about.txt

Krelboyne Go is the gaming sister of KrelboyneOS, built the same way with live-build and installed with Calamares.

It keeps only what a handheld needs: games, a browser, sound, Wi-Fi and a touch keyboard. It is made for the original Legion Go, not the Legion Go S or Go 2.

status.log

0.1.0 alpha. It runs installed on a Legion Go, with Steam games through Proton, emulators through ES-DE and RetroArch, and the built-in controller working in both.

Some hardware isn't tested yet (see below), so expect rough edges. Problems are welcome in the Discord.

What's inside

games
  • Steam, with Proton for Windows games
  • ES-DE game frontend
  • RetroArch with NES, SNES, Genesis, Game Boy, GBA and DS cores
  • Built-in controller works in Steam, ES-DE and RetroArch
made-for-the-go
  • Turns the portrait panel to landscape at 144 Hz on the login screen and desktop
  • Text sized for the 8.8 inch screen (160 DPI)
  • Tap-to-click on the touchpad
  • Onboard touch keyboard, also on the login and lock screen
everyday
  • Xfce on LightDM, Arc-Dark theme, Papirus icons
  • Firefox ESR
  • PipeWire sound with a volume control in the panel
  • Wi-Fi and firmware, clock set from the internet

Download

krelboynego-amd64.hybrid.iso

Latest ISO, about 2.1 GB. Download the checksum file too, into the same folder.

krelboynego-amd64.hybrid.iso ~2.1 GB
krelboynego-amd64.hybrid.iso.sha256 checksum

Each release on the Releases page lists its SHA-256 hash too. It should match the one in the .sha256 file.

Check it after downloading:

$ sha256sum -c krelboynego-amd64.hybrid.iso.sha256

Then put the ISO on a USB stick or microSD card with Ventoy, balenaEtcher or dd.

0.1.0 alpha: try it live first. Installing with Erase disk replaces whatever is on the SSD, Windows included.
$

Install it on the Go

boot-live
  • Turn Secure Boot off in the Go's BIOS. With it on, the Go doesn't show its USB or card port as a boot device.
  • Boot from the USB stick or card and pick the live entry
  • Check that Wi-Fi, sound and the controller work for you
install

Double-click Install Krelboyne Go on the desktop. On the partitioning page, check that the internal SSD is selected, not your USB stick or card.

Back up anything you want to keep from Windows first.
